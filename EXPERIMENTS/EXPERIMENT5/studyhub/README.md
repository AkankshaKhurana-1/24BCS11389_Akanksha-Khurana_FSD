# 📚 StudyHub - Student Productivity & Task Manager

A student study productivity hub built with React 19, Vite, Context API, and Lucide Icons.

## 🚀 Features

- 📝 **Task & Assignment Manager**: Create, prioritize, filter, and track academic assignments and study goals.
- 👤 **Student Profile Context**: Track study streak, completed goals, and student profile details using React Context.
- 📊 **Productivity Metrics**: Real-time completion rates and stats dashboard.
- 🎨 **Dark / Light Mode**: Built-in responsive layout with theme support.

## 💻 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
