# ⏱️ ChronoCraft - Precision Stopwatch Application

A modern, high-precision, feature-rich Stopwatch built with React, Vite, and Lucide Icons.

## 🚀 Features

- ⚡ **High Precision Timing**: Millisecond-accurate digital clock powered by high-resolution web animation frame timers.
- 🏁 **Lap & Split Recording**: Record unlimited laps with lap-by-lap time difference and cumulative split time.
- 📊 **Smart Lap Analytics**: Automatically highlights **Fastest**, **Slowest**, and calculates **Average** lap times.
- 🎨 **Sleek UI**: Dark/Light mode theme switching with responsive typography and progress indicator ring.
- ⌨️ **Keyboard Shortcuts**:
  - `Space` : Start / Pause / Resume
  - `L` : Record Lap
  - `R` : Reset Stopwatch
- 📥 **Export Laps**: Download lap records as CSV.
- 🔔 **Audio Feedback**: Subtle click sound effects on actions (can be muted).

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Lucide React Icons**
- **CSS3 with Custom Properties & Glassmorphism design**

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
