# 💱 ApexConvert - Real-Time Currency Converter

A modern, responsive, real-time currency conversion application built with React, Vite, and Lucide Icons.

## 🚀 Features

- 🌐 **Real-time Foreign Exchange Rates**: Accurate live conversion rates using fallback API feeds.
- 🔄 **Instant Currency Swapping**: Swap base and target currencies seamlessly.
- 📜 **Conversion History**: Logs recent exchange searches and conversions.
- 🎨 **Dark / Light Theme Toggle**: Seamless UI mode switching.

## 💻 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
