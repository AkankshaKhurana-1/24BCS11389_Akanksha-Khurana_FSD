# 🔢 OmniCount - Modern React Counter Application

An interactive, responsive Counter application built with React 19, Vite, and Lucide Icons.

## 🚀 Features

- ➕ **Increment / Decrement / Reset**: Core counter controls with animated number transitions.
- ⚙️ **Configurable Step Size**: Customize increment/decrement step sizes (`+1`, `+5`, `+10`, or custom).
- 🎯 **Target Goal Tracking**: Set a target goal and monitor visual progress bars.
- 📜 **Action History Log**: Real-time log of all increment, decrement, and reset actions with timestamping.
- ⌨️ **Keyboard Shortcuts**:
  - `ArrowUp` or `+` : Increment
  - `ArrowDown` or `-` : Decrement
  - `R` : Reset
- 🎨 **Dark / Light Theme**: Built-in theme switcher with CSS custom properties.

## 💻 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
